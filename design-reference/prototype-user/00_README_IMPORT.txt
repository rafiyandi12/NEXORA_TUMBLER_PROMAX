NEXORA USER — IMPORT KE FIGMA

Plugin yang dipakai: html2figma (Figma Community), bukan html.to.design.
Plugin: https://www.figma.com/community/plugin/1668745510469345388
Website resmi: https://html2figma.com/

Cara import:
1. Extract ZIP.
2. Buka file Figma.
3. Jalankan plugin html2figma.
4. Drop satu file .html ke area import.
5. Pilih viewport 390 px / Mobile lalu Import.
6. Ulangi per file sesuai nomor.

File dibuat dengan CSS langsung di <style>, tanpa JavaScript/CDN Tailwind. Logo NEXORA dibuat sebagai text nyata dan icon SVG inline supaya layer tetap editable.
Foto produk menggunakan URL gambar resmi Corkcicle; koneksi internet aktif diperlukan saat import agar gambar remote dapat diambil.
